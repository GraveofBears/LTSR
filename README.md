# 👻 Let the Spirits Rest 👻

**Let the Spirits Rest** is an atmospheric, ritual‑themed puzzle game where players use mystical items to help wandering ghosts finally move on. Explore haunted scenes, solve item‑based challenges, and race against a dwindling candle to release every spirit before the flame dies out.

## 🎮 How to Play

Interact using **Point & Click** or the following **Hotkeys**:

- ☀️ = 1  
- 🌀 = 2  
- 🌙 = 3  
- ⭐ = 4  
- 🧂 = Q  
- ✝️ = W  
- 🌿 = E  
- 🔔 = R  

**Boss Memory Items** must be clicked directly when discovered.
